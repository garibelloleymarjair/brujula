CÓMO FUNCIONA

Una interfaz.
Distintas formas de explorar.

Brújula es una aplicación de escritorio construida con Electron. Integra una interfaz propia y accesos a servicios web de terceros. Las búsquedas web y las respuestas de asistentes externos dependen del servicio que elijas.

La versión actual también incluye una función experimental de índice local; no debe confundirse con un índice global que rastree toda internet.

EL PROYECTO

Conoce Brújula

Una iniciativa independiente que busca reunir navegación, búsqueda y conocimiento en una experiencia sencilla. El repositorio contiene la página pública y el código de la aplicación de escritorio.
